# Step 1f: RC Snubber 损耗建模

## 模型概述

在 step1e 基础上增加 RC snubber 损耗，用于模拟开关损耗等高频损耗。

**关键发现**：Snubber 功率不只消耗在 R_snubber 上，有一部分消耗在 MOSFET 上。

---

## Snubber 参数

- C_snub = 500pF / 4.7nF (测试两组)
- R_snub = 5Ω

---

## Snubber 损耗公式

### 简化公式（不准确）
```
P_snub = 0.5 × C × Vout² × fsw  ❌
```

### 修正公式（考虑实际开关电压）
```
关断: C 从 IL_peak×Rdson 充电到 Vout+Vf
开通: C 从 Vout+Vf 放电到 IL_valley×Rdson

E_off = 0.5 × C × ((Vout+Vf)² - (IL_peak×Rdson)²)
E_on  = 0.5 × C × ((Vout+Vf)² - (IL_valley×Rdson)²)
P_snub = (E_on + E_off) × fsw
```

### 功率分配

Snubber 功率不是全部消耗在 R_snubber 上：
- **R_snubber 消耗**：充放电电流流过 R 产生的热量
- **MOSFET 消耗**：C 充放电过程中，部分能量通过 MOSFET 释放

## 结论

1. **模型精度**：三组误差都在 5% 以内，模型可用 ✅
2. **电容越大误差越大**：4.7nF 误差 (4%) > 500pF 误差 (0.6%)
3. **功率分配**：snubber 功率 = R_snubber 损耗 + MOSFET 额外损耗
