## 方法 1: 理论公式

**状态**: ⏳ 待建立

**思路**:
- 基于理想 Boost 公式推导输出纹波解析解
- 考虑两相交错 180° 相移的纹波抵消
- 考虑 D > 0.5 时的重叠区

**公式** (待验证):
```
D > 0.5 时:
ΔI_out = ΔIL × (2D - 1)

ΔV_cout = ΔI_out / (8 × Cout × fsw × 2)
        = ΔI_out / (16 × Cout × fsw)
```

## 方法 2: 数值计算 (时域仿真)

**状态**: ✅ 已有工具 (calc-tools-v2)

**来源**: `calc-tools-v2/docs/boost-ripple-calc.md`

**方法**:
1. 生成单相二极管电流波形 Id(t) (2000 点/周期)
2. 两相叠加: Id_total = Id1 + Id2 (180° 相移)
3. 电容电流: Ic = Id_total - Iout
4. 积分求电压: Vc = ∫Ic·dt / Cout
5. ESR 压降: Vesr = Ic × ESR
6. 总纹波: Vripple = Vc + Vesr

**特点**:
- 时域仿真，波形直观
- 可处理 DCM 模式
- 可加入 ESR 影响

## 方法 3: 迭代计算

**状态**: ✅ 已有代码 (step1e/step1f)

**方法**:
1. η 预设 → IL_avg → D (KCL) → ΔIL → 损耗 → 迭代收敛
2. 输出: D, IL_avg, ΔIL, IL_peak, IL_valley, η

**特点**:
- 考虑实际损耗 (Vf, DCR, Rds, Snubber)
- 精度高 (误差 <1%)
- 但只计算稳态电流，不直接输出纹波

**用途**: 为数值计算提供准确的 D, ΔIL 等输入参数
