## 📅 版本历史

### Step 1f: 加入 RC Snubber 损耗 (2026-06-03) ✅
**状态**: 当前最佳模型，作为后续双相模型的基础。

**核心更新**:
- 在 Step 1e 基础上增加了 RC Snubber 的充放电损耗建模。
- 明确了 Snubber 能量分配：电容 $C$ 存储的能量 $0.5CV^2$ 在放电时部分消耗在电阻 $R_{snub}$ 上，部分消耗在 MOSFET 上，但总损耗仅由 $C$ 和电压摆幅决定。

### Step 1e: η 预设 + KCL 反推 (2026-05-29) ✅
**状态**: 核心算法突破，确立了自洽迭代框架。

**核心更新**:
- 彻底放弃基于伏秒平衡计算占空比 $D$ 的思路。
- 确立了全新的迭代逻辑：`η (预设) → IL_avg → D (KCL) → ΔIL (含R) → 损耗 → η_new → 循环`。
- 发现考虑 $R_{ds}$ 和 DCR 压降后，实际 $\Delta I_L$ 会降低约 12.8%。

**关键教训**: D 从 KCL 反推的误差仅为 0.05%，远低于伏秒平衡法的 3.5%。

---

### Step 1c / 1d: 伏秒平衡法 + 全损耗 (2026-05-29) ❌ 已废弃
**状态**: 探索分支，已移至 `archive/`。

**尝试与失败**:
- 试图用理想的伏秒平衡方程 $D = 1 - Vin/(Vout+Vf)$ 锁定占空比，然后通过功率平衡迭代电流。
- **失败原因**：实际开关过程中，MOSFET 导通电阻会导致有效输入电压降低，伏秒平衡在仿真中并不严格成立。强行锁定 D 导致模型电流与仿真产生 >3.5% 的差距。
