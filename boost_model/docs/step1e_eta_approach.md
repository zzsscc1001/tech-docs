# Step 1e: η 预设 + KCL 反推

## 模型概述

**核心思想**：不使用伏秒平衡求 D，改用 KCL 反推。

**方法**：η 预设 → IL_avg → D (KCL) → ΔIL → 损耗 → η_new → 迭代收敛

**关键发现**：D 从 KCL 反推比伏秒平衡准确得多（误差从 3.5% 降到 0.05%）

---

## 迭代流程

```
输入: Vin=9V, Vout=30V, Iout=0.5A, L=10µH, fsw=400kHz
      Vf=0.7V, DCR=300mΩ, Rds=300mΩ

┌─────────────────────────────────────────────────┐
│ Step 1: η 预设 (初始: η = Vout/(Vout+Vf))      │
│         IL_avg = Vout·Iout / (η·Vin)            │
├─────────────────────────────────────────────────┤
│ Step 2: D (KCL 反推)                            │
│         Iout = (1-D)·IL_avg                     │
│         D = 1 - Iout/IL_avg                     │
├─────────────────────────────────────────────────┤
│ Step 3: ΔIL (考虑 Rds+DCR)                      │
│         R_ton = Rds + DCR                       │
│         ΔIL = (Vin - IL_avg·R_ton)·D / (L·fsw) │
│                                                 │
│         验证 (Toff 侧):                         │
│         ΔIL = (Vout+Vf-Vin+IL_avg·DCR)·(1-D)   │
│              / (L·fsw)                          │
├─────────────────────────────────────────────────┤
│ Step 4: 峰值/谷值                               │
│         IL_peak = IL_avg + ΔIL/2                │
│         IL_valley = IL_avg - ΔIL/2              │
├─────────────────────────────────────────────────┤
│ Step 5: RMS (三角波近似)                         │
│         IQ_rms = √(D·(IL_avg² + ΔIL²/12))     │
│         ID_rms = √((1-D)·(IL_avg² + ΔIL²/12)) │
├─────────────────────────────────────────────────┤
│ Step 6: 损耗 & η 更新                           │
│         P_MOS = IQ_rms²·Rds                     │
│         P_DCR = IL_avg²·DCR                     │
│         P_diode = Vf·Iout                       │
│         η_new = Pout / (Pout + P_sum)           │
│                                                 │
│         收敛? → 否则返回 Step 1                  │
└─────────────────────────────────────────────────┘
```

---

## 公式推导

### D 的计算 (KCL)

```
二极管平均电流 = Iout (输出电流)
二极管只在 (1-D)T 期间导通
导通期间平均电流 = IL_avg

所以: Iout = (1-D)·IL_avg
      D = 1 - Iout/IL_avg
```

**优势**：不依赖损耗模型，直接从 KCL 约束反推。

### ΔIL 的计算 (考虑电阻压降)

**Ton 期间**:
```
VL(t) = Vin - i(t)·(Rds+DCR)
∫₀^Ton VL dt = Vin·Ton - R_ton·∫₀^Ton i(t) dt

其中: ∫₀^Ton i(t) dt = IL_avg·Ton (三角波面积)

→ ΔIL = (Vin - IL_avg·R_ton)·D / (L·fsw)
```

**Toff 侧验证**:
```
ΔIL = (Vout + Vf - Vin + IL_avg·DCR)·(1-D) / (L·fsw)
```

两个公式应一致（自洽检查）。

## 关键发现

1. **D 从 KCL 反推比伏秒平衡准确得多**
   - 伏秒平衡法: D 误差 3.5%
   - KCL 反推法: D 误差 0.05%

2. **ΔIL 考虑 Rds+DCR 压降后降低 12.8%**
   - 无电阻: ΔIL = 1.665A
   - 有电阻: ΔIL = 1.451A

3. **迭代收敛快**（13 步）

4. **伏秒平衡在仿真中不准确的原因**
   - 假设理想开关波形（方波）
   - 实际仿真有开关过渡过程
   - Rds 在 Ton 期间有压降，影响有效电压
