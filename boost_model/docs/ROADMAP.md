# Dual Phase Boost 迭代计算模型 — 系统工程路线图

## 1. 项目愿景与目标

**最终目标**：建立一个高精度的**双相交错 (Dual Phase) Boost 迭代计算模型**，能够从基础物理参数（Vin, Vout, L, fsw, Rds, DCR, Vf, C_snub 等）出发，全自动地计算出稳态工作点、损耗分布、各阶段电流波形，并最终输出精确的**输出纹波电压 ($\Delta V_{cout}$)**。

**核心方法论**：
- **模型驱动**：摒弃理想方波和简单的伏秒平衡，采用 $\eta$ 预设 + KCL 反推占空比 $D$ 的自洽迭代方法。
- **闭环验证**：每前进一步，必须通过电路仿真（SPICE/PLECS）进行交叉验证，确保误差收敛在可接受范围（通常 < 1%）。
- **模块化演进**：从单相理想模型出发，逐步加入非理想因素，最后扩展至双相交错与纹波计算。

## 2. 演进路线图 (Roadmap)

整个项目分为四个主要阶段（Phase），目前我们正处于 Phase 3 的攻坚期。

### Phase 1: 单相基础稳态模型（已完成 ✅）
*目标：建立单相 Boost 的高精度损耗与稳态工作点模型。*

- **Step 1**: 理想 CCM 公式推导与验证。
- **Step 1b**: 引入恒定二极管压降 $V_f$。
- **Step 1c/1d**: 尝试使用伏秒平衡计算 $D$ 并加入全损耗（验证失败，已废弃并归档）。
- **Step 1e**: 引入核心突破——**$\eta$ 预设 + KCL 反推 $D$**，加入 $R_{ds(on)}$ 和 DCR 损耗。仿真验证误差 < 0.5%。
- **Step 1f**: 加入 RC Snubber 充放电损耗模型。明确了 Snubber 功率在电阻和 MOSFET 上的分配。

*产出物*：`step1f_snubber.py`，这是目前最可靠的单相基础计算引擎。

### Phase 2: 双相交错时序理论推导（进行中 🔄）
*目标：解决双相交错引入的复杂时序问题，特别是 DCM 模式下的电流波形叠加。*
*(注：这部分工作目前在 `dp_boost_theo_temp/` 目录下进行，后续将整合)*

- **分类框架**：按 CCM/DCM 和 $D_d$ 与 0.5 的关系，分为 A, B, C, D 四种宏观工况。
- **Case A (CCM, $D_d < 0.5$)**：完成理论推导与代码实现。
- **Case C (DCM, $D_d < 0.5$)**：完成 C1, C2a, C2b 三个子情况的推导，解决 $D$ 随负载变化和波形跨越周期边界的问题。
- **Case B (CCM, $D_d > 0.5$)**：**待推导**。
- **Case D (DCM, $D_d > 0.5$)**：**待推导**。

*产出物*：一套能够根据负载自动判定工况并输出分段时域函数 $I_d(t)$ 的理论框架。

### Phase 3: 双相交错迭代计算模型整合（即将开始 🚀）
*目标：将 Phase 1 的高精度损耗模型与 Phase 2 的时序理论结合，计算最终纹波。*

- **步骤 3.1**：将 `step1f_snubber.py` 的迭代内核扩展为双相（输入功率减半，交错相移）。
- **步骤 3.2**：将 `dp_boost_theo_temp/` 中的时序分类逻辑（`classifier.py`）接入迭代循环，使用迭代收敛后的真实 $D$ 和 $\Delta I_L$ 判断工况。
- **步骤 3.3**：实现数值积分模块。基于推导出的总二极管电流 $I_{d\_total}(t)$，计算电容电流 $I_c(t) = I_{d\_total}(t) - I_{out}$，积分求得输出电容电压纹波 $\Delta V_{cout}$。
- **步骤 3.4**：**仿真闭环验证**。搭建完整的双相交错 SPICE 仿真模型，提取稳态纹波，与计算模型对比。

### Phase 4: 高级特性与小信号模型（长期规划 📅）
*目标：完善动态响应与极端工况建模。*

- 考虑输出电容的 ESR 和 ESL 对纹波的影响。
- 推导小信号传递函数（$G_{vd}$），为电压环/电流环路补偿设计提供依据。
- 考虑寄生电感引起的开关节点振铃与高频 EMI 预估。

## 3. 已知问题与技术债 (Tech Debt)

1. **$\Delta I_L$ 的 Ton/Toff 不一致问题**：在 Step 1e/1f 中，从 Ton 侧积分得到的 $\Delta I_L$ 与从 Toff 侧计算的 $\Delta I_L$ 存在约 2% 的不一致（如 `1.4559A vs 1.4268A`）。这是因为模型简化了非线性过渡过程，需要在后续版本中评估此误差对最终纹波的影响。
2. **文档结构碎片化**：历史探索文件与当前核心代码混杂，`dp_boost_theo_temp/` 作为临时目录游离在主工程之外，需要统一收拢到标准的包结构中。
3. **Snubber 模型的局限**：目前的 Snubber 模型假设电容在一个周期内完全充放电，未考虑 $\tau = RC$ 远大于导通时间时的未完全放电情况。
