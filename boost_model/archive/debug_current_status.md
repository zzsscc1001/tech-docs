# Boost 模型 Debug 文档 — 当前状态

## 模型概览

**目标**: 从物理参数直接计算 Boost 稳态工作点

**输入参数**: Vin, Vout, Iout, L, fsw, Vf, DCR, Rds_on

**核心发现**: D 与损耗解耦，IL_avg 需要迭代

## 当前迭代流程

```
输入: Vin=9V, Vout=30V, Iout=0.5A, L=10µH, fsw=400kHz
      Vf=0.7V, DCR=300mΩ, Rds=300mΩ

┌─────────────────────────────────────────────────┐
│ Step 1: D = 1 - Vin/(Vout+Vf)                   │
│         = 1 - 9/30.7 = 0.7068                   │
│         ← 伏秒平衡，与 DCR/Rds 无关              │
├─────────────────────────────────────────────────┤
│ Step 2: IL_avg = Iout/(1-D) = 1.7056A           │
│         ← 初始值 (忽略损耗)                       │
├─────────────────────────────────────────────────┤
│ Step 3: 迭代 (功率平衡)                           │
│                                                 │
│   ΔIL = Vin·D/(L·fsw) = 1.590A  (固定)         │
│                                                 │
│   循环:                                          │
│     IQ_rms = √(D·(IL²+ΔIL²/12))               │
│     P_MOS  = IQ_rms² · Rds                     │
│     P_DCR  = IL_avg² · DCR                     │
│     P_diode = Vf · Iout = 0.35W                │
│     IL_new = (Pout + P_MOS + P_diode + P_DCR)   │
│              / Vin                              │
│     收敛? → break                               │
│                                                 │
│   15 步收敛 → IL_avg = 1.9203A                  │
├─────────────────────────────────────────────────┤
│ Step 4: 输出                                     │
│   D=0.7068, IL_avg=1.920A, ΔIL=1.590A          │
│   IL_peak=2.716A, IL_valley=1.125A              │
│   η=86.79%, Ploss=2.283W                        │
└─────────────────────────────────────────────────┘
```

## 仿真对比

**仿真条件**: Vin=9V, Vout=30V, Iout=0.5A, L=10µH, fsw=400kHz
MOSFET: 仅 Rds_on=300mΩ, 二极管: Vf=0.7V, 电感 DCR=300mΩ

| 参数 | 模型 | 仿真 | 误差 |
|------|------|------|------|
| IL_peak | 2.716A | 2.648A | +2.5% |
| IL_avg | 1.920A | 1.933A | -0.7% |
| IL_valley | 1.125A | 1.199A | -6.2% |

**KCL 反推 D**: D = 1 - 0.5/1.933 = **0.7413** (仿真)
**模型 D**: 0.7068 → **差距 3.5%**

## 差距分析

### 可能原因 1: Vout 纹波影响
仿真 Vout 纹波 40mV (Vpp)。实际平均 Vout 可能不是精确 30V。
- 若 Vout_avg = 30.02V → D = 1 - 9/30.72 = 0.7070 (影响极小)
- 结论: **排除**，影响 < 0.03%

### 可能原因 2: MOSFET 开关过程
仿真用了仅 Rds_on 的 MOS 模型，但实际仿真中:
- MOSFET 开关有过渡过程 (非理想方波)
- 开关瞬间电流/电压有尖峰
- 这些影响 **无法用纯 Rds 模型捕获**

### 可能原因 3: 二极管反向恢复
仿真中的二极管模型可能有反向恢复电流，增加额外损耗。

### 可能原因 4: D 的计算本身
模型假设 D 完全由伏秒平衡决定 (Vf only)。
实际仿真中，Rds_on 在 Ton 期间有压降 (Vin_eff < Vin)。
虽然伏秒平衡中 Rds 的贡献理论上会通过 IL 调整抵消，
但仿真器可能有不同的收敛行为。

## KCL 方法 (仿真反推)

用户提出的思路:

```
二极管平均电流 (全周期) = Iout = 0.5A
二极管只在 (1-D)T 期间导通
导通期间平均电流 = IL_avg

所以: Iout = (1-D) × IL_avg
      → D = 1 - Iout/IL_avg
```

**这个方法不依赖损耗模型，直接从仿真 IL_avg 反推 D。**

用仿真数据验证: D = 1 - 0.5/1.933 = 0.7413
