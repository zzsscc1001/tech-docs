# 情况 C：DCM + 二极管占空比 $< 0.5$

> 条件：DCM，$D_d = \delta < 0.5$
> 轨迹 1（A→C）的轻载端，同步关沿，不交叠

---

## 1. 前提条件

$$\text{DCM：} I_{L,valley} = I_{L,avg,sp} - \frac{\Delta I_L}{2} \leq 0$$

$$D_d = \delta = \frac{D \cdot V_{in}}{V_{out}+V_f-V_{in}} < 0.5$$

DCM 约束：$D + \delta < 0.5$（diode 在 $T_s/2$ 之前降为零）
