# 双相交错 180° Boost — 分类框架与负载变化轨迹

> 继承单相模型（见 `01_single_phase.md`）
> 功率定义：$P_{dp}$ = 双相总功率，$P_{sp} = P_{dp}/2$ = 单相功率

---

## 1. 命名约定

| 符号 | 定义 | 说明 |
|------|------|------|
| $D$ | 开关占空比 | 开关导通时间 / $T_s$ |
| $D' = 1-D$ | 开关关断时间比 | — |
| $D_d$ | 二极管占空比 | 二极管实际导通时间 / $T_s$ |
| $m$ | TOFF 下降斜率 | $\frac{V_{out}+V_f-V_{in}}{L}$（正值） |

### CCM 下

$$D_d = D' = 1-D$$

### DCM 下

$$D_d = \delta = \frac{\Delta I_L}{m \cdot T_s} = \frac{D \cdot V_{in}}{V_{out}+V_f-V_{in}} < D'$$

二极管在电感电流降为零时截止，导通时间短于开关关断时间。

## 3. 轨迹 1：A → C（无交叠）

> 从满载逐渐降低负载，$D_d$ 单调递减，始终 $< 0.5$。

### 变化过程

| 阶段 | 模式 | $D_d$ | 说明 |
|------|------|-------|------|
| 满载 | CCM (A) | $D_d = D' < 0.5$ | 额定工作点 |
| 临界点 | CCM/DCM 边界 | $D_d = D' < 0.5$ | $I_{L,valley} = 0$ |
| 轻载 | DCM (C) | $D_d = \delta < D' < 0.5$ | diode 导通时间进一步缩短 |

### 特性

- **永远不交叠**：$D_d$ 始终 $< 0.5$
- **同步方式统一**：全程使用同步关沿时序
- **波形结构一致**：两个三角脉冲 + 两段死区，只是 DCM 下脉冲底宽更窄
- **输出纹波计算相对简单**：无交叠意味着 $I_d(t)$ 分段独立，积分容易

---

## 4. 轨迹 2：B → D（有交叠）

> 从满载逐渐降低负载，$D_d$ 单调递减，始终 $> 0.5$。

### 变化过程

| 阶段 | 模式 | $D_d$ | 说明 |
|------|------|-------|------|
| 满载 | CCM (B) | $D_d = D' > 0.5$ | 额定工作点 |
| 临界点 | CCM/DCM 边界 | $D_d = D' > 0.5$ | $I_{L,valley} = 0$ |
| 轻载 | DCM (D) | $D_d = \delta$ 从 $D'$ 递减 | 可能穿过 0.5 进入无交叠区 |

### 特性

- **CCM 阶段一定交叠**：$D_d = D' > 0.5$，两路 diode 导通区间重叠
- **同步方式**：同步开沿（标准 180° 延迟 $T_s/2$）
- **DCM 阶段**：$D_d = \delta$ 随负载降低而减小，可能在某个点穿过 0.5 变为无交叠（退化为类似情况 C 的时序）
- **输出纹波计算更复杂**：交叠期间 $I_d(t)$ 是两路 diode 电流之和
