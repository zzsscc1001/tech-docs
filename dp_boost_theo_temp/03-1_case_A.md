# 情况 A：CCM + 二极管占空比 $< 0.5$

> 条件：CCM，$D > 0.5$，$D_d = D' = 1-D < 0.5$
> 同步方式：同步关沿
> 波形特征：两个三角脉冲 + 两段死区，完全不交叠

---

## 1. 前提条件

$$\text{CCM：} I_{L,valley} = I_{L,avg,sp} - \frac{\Delta I_L}{2} > 0$$

$$D > 0.5 \quad \Leftrightarrow \quad D_d = 1-D < 0.5$$

---

## 2. 时序

| 区间 | 时间范围 | SW1 | SW2 | D1 | D2 | 说明 |
|------|----------|-----|-----|----|----|------|
| ① | $[0, \ (D-0.5)T_s]$ | ON | OFF | ✗ | ✗ | 死区 |
| ② | $[(D-0.5)T_s, \ 0.5T_s]$ | OFF | OFF | ✗ | ✓ | 仅 D2 |
| ③ | $[0.5T_s, \ DT_s]$ | OFF | ON | ✗ | ✗ | 死区 |
| ④ | $[DT_s, \ T_s]$ | OFF | OFF | ✓ | ✗ | 仅 D1 |

每路 diode 导通时间：$(1-D)T_s$

两段死区总时长：$(2D-1)T_s$

---

## 3. D1 电流

$$I_{d1}(t) = I_{L,peak} - m(t - DT_s), \quad t \in [DT_s, \ T_s]$$

| 边界 | 值 |
|------|----|
| $t = DT_s$ | $I_{L,peak}$ |
| $t = T_s$ | $I_{L,valley}$ |

---

## 4. D2 电流

$$I_{d2}(t) = I_{L,valley} + m\bigl(t - (D-0.5)T_s\bigr), \quad t \in [(D-0.5)T_s, \ 0.5T_s]$$

| 边界 | 值 |
|------|----|
| $t = (D-0.5)T_s$ | $I_{L,valley}$ |
| $t = 0.5T_s$ | $I_{L,peak}$ |

---

## 5. 总 diode 电流 $I_d(t)$

**区间① $t \in [0, \ (D-0.5)T_s]$ — 死区**

$$I_d(t) = 0$$

**区间② $t \in [(D-0.5)T_s, \ 0.5T_s]$ — D2 导通**

$$I_d(t) = I_{L,valley} + m\bigl(t - (D-0.5)T_s\bigr)$$

**区间③ $t \in [0.5T_s, \ DT_s]$ — 死区**

$$I_d(t) = 0$$

**区间④ $t \in [DT_s, \ T_s]$ — D1 导通**

$$I_d(t) = I_{L,peak} - m(t - DT_s)$$

---

## 6. 波形特征

```
Id
 ▲
 │    ╱╲          ╱╲
 │   ╱  ╲        ╱  ╲
 │  ╱    ╲      ╱    ╲
 │ ╱      ╲    ╱      ╲
 │╱        ╲  ╱        ╲
 ┼──────────╲╱──────────╲──→ t
 0    ①   ②   ③    ④   Ts
      死区 D2  死区  D1
```

- 两个对称三角脉冲
- D2 上升斜坡，D1 下降斜坡
- 中间隔两段死区（$I_d = 0$）
- 脉冲峰值 = $I_{L,peak}$，谷值 = $I_{L,valley}$
